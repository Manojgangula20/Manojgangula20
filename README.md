## 🧠 Engineering Philosophy

I try to approach engineering problems from more than just the implementation layer.

My focus is:

```text
Understand the problem
        ↓
Design the architecture
        ↓
Build modular components
        ↓
Automate repetitive work
        ↓
Secure the system
        ↓
Test and validate
        ↓
Observe and improve
```

I care about **why a technology is used**, not just how to use it.

For example:

- Private networking → reduce unnecessary public exposure
- Cloud NAT → outbound connectivity without public VM IPs
- Terraform modules → reusable infrastructure design
- Remote state → centralized infrastructure state
- OIDC/WIF → avoid long-lived cloud credentials
- Reusable workflows → eliminate duplicated CI/CD logic
- Approval gates → human control before infrastructure changes
